方寸湾 · PIXEL BAY / 城市交通版 v2.2
一个可游玩的3D像素城市模拟建设原型。在第一阶段建设系统上加入抽样交通、信号路口、拥堵观察与车辆跟随，并保留写实光影实验。

运行
在项目目录执行：python3 -m http.server 4173 --directory dist
用现代桌面浏览器访问 http://localhost:4173 。Three.js已随项目附带，无需npm依赖。
离线单文件版 pixel-bay.html 可在支持WebGL2的浏览器直接打开；源码版应通过HTTP启动。
交通回归测试：node tests/traffic.mjs（11组）。
逻辑回归测试：node tests/simulation.mjs（14组）。
场景专项回归：node tests/scene-audit.mjs（10组，含14,136组几何组合、道路与车辆、600次混合操作）。

玩法与新增能力
建造目录：5种住宅、6种商业、3种公园、6种公共服务建筑。
DIY工坊：7种风格、1–12层、1–3格宽深、4个朝向、墙面颜色、3种屋顶。
模块：庭院、围墙、车库、泳池、露台、太阳能。组件为固定位置可选模块，并非自由拖拽建模器。
蓝图：命名保存、复用、JSON导入导出，最多保留40份。
城市：道路连续拖绘、跨水自动建桥，多格建筑占地校验、整栋拆除、三级升级。
地形：空闲地块填土或开挖水域；当前不含地形高度与坡度。
撤销：最近60次建设操作，可重做；不会倒退已结算的日期与财政收入。重载档案后历史清空。
经济：人口与就业、水电、税收维护；商业分配附近客流，酒店根据游客计算经营活动。
公共服务：教育、医疗、消防、治安、文化、文体的范围与容量影响幸福和地价。

操作
左键建造或检查；道路工具下按住左键拖动连续规划，松开提交整段。
右键拖动旋转；滚轮缩放；WASD或查看模式拖动平移。
Q/E旋转；H恢复视角；空格暂停；1–9切换基本工具。
B建筑目录；G光影设置；T交通观察；Ctrl/⌘ Z撤销；Ctrl/⌘ Shift Z重做。
DIY预览内更改参数、旋转，再按“使用这份设计”选择沿路空地。
游戏每8秒结算一天；连续昼夜为独立的10分钟视觉周期，可以手动调时刻。

存档
浏览器自动保存，另有3个手动城市档案。支持城市JSON导入导出，导入前保留恢复备份。
兼容V1旧城市，迁移为V2；损坏数据被拒绝，可恢复最近有效备份。
每个地址/浏览器的存档独立。在线站点、localhost和离线文件互不共享存储；请用导出/导入迁移。
只有在页面运行时进行模拟。建议定期导出JSON，浏览器清理数据会影响本地存档。

渲染
Three.js r164.1/WebGL2，程序化体素几何与PBR材质、天空环境照明、阴影。
河面采用镜像相机平面反射、Fresnel/GGX与吸收；后处理包含屏幕空间遮蔽、间接光近似、短程接触射线、时域重投影和锐化。
这是浏览器混合渲染实验，不是完整实时路径追踪，也不是NVIDIA DLSS。
三档质量、可独立关闭效果；历史重建约207万像素上限，减少高分辨率附件内存。
已使用实例化批次；人口/财政更新不再重建所有建筑。大地图分区LOD和流式加载尚未实现。

当前边界
32×32地图。最多64个抽样出行任务，数量随居民增加。车辆在住宅与工作/商业/公园之间按道路最短路径出行。
连续车道曲线、车距检测、信号等待、交叉口互斥与队列已实现；未实现逐居民出行、变道、公交或玩家驾驶。
天气、街景漫游、地形高度、大型交通枢纽、灾害节日、随机收藏、AI建设和Mod运行时仍在后续路线。
服务目前通过统计模型影响城市指标，尚无救护车/消防出勤与具体居民AI。

交通观察（2026-11-10）
点击底部「⇄ 交通」或按T，打开实时面板；面板不会暂停城市。
开启「道路拥堵图层」查看最近一段时间的等待分布；点击关注路段可以定位。
「跟随一辆车」切换相机跟随，显示任务和路径；「换一辆」切换车辆。建造、拖动地图、WASD、H或Esc可退出跟随。
信号路口按东西/南北轮流放行，清空阶段全红。车流按模拟秒推进，速度按钮1×/2×/3×同时影响交通与经济；暂停会停止车辆和信号。
交通是基于建筑的抽样模型，不代表每位居民的一对一出行。当前交通指标用于观察与道路规划，尚未反向影响工资、税收或幸福度。
道路拓扑变化时取消当前抽样行程并重新组织；载入/重开后重建交通，不保存每辆车的位置及本次会话计数。城市V2存档保持兼容。
详见 TRAFFIC-RELEASE.txt。
